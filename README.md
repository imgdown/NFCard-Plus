# NFCard-Plus

NFC 公交卡读取工具（安卓），对已停更的开源项目 [NFCard](https://github.com/sinpolib/nfcard) 的**全新重写**：
不复制原项目代码，仅依据公开行业规范（交通部《公共交通 IC 卡技术规范》、PBOC 电子钱包规范）实现，
许可证为 **Apache-2.0**（原项目为 GPL-3.0，本项目非其衍生作品）。

## 功能（v1.0）

- **自动读取**：贴卡自动识别卡种；多合一卡（公交/社保/银联）逐个应用读取并全部展示，单个应用失败不影响其他。
- **手动读取**：自动识别不全或非标卡时，手动指定卡种强制读取。
- **交通联合卡增强**（原版不支持）：
  - 地铁进出站状态（已进站未出站 / 已出站）
  - 进出闸时间、线路与站点（如"（郑州）3号线37号"）、城市
- 余额（含透支信息）、卡号、有效期、发卡城市、最近交易明细。

### 支持卡种

| 卡种 | 说明 |
| --- | --- |
| 交通联合（China T-Union） | 全国交通一卡通，含地铁进出站信息 |
| 城市互联互通 | 住建部标准互联互通卡 |
| 北京一卡通 | 北京市政交通一卡通 |
| 武汉通 | |
| 深圳通 | |
| 标准 PBOC 电子钱包 | 其他符合 PBOC 规范的公交卡 |

后续版本计划：ETC 卡、银联电子现金、更多城市卡种、鸿蒙 NEXT 版（工程骨架已就绪，见 `harmony/`）。

## 界面

底部三栏：**自动读取**（默认页）／**手动读取**／**关于**（版本、项目地址、下载地址、支持卡种）。

## 隐私

仅在本地通过 NFC 读取卡片公开信息，不联网上传任何卡片数据，不收集个人信息。
仓库与 CI 日志中不含任何密钥；发布签名密钥保存在 GitHub Secrets。

## 构建

环境：JDK 17、Android SDK（compileSdk 35）。

```bash
./gradlew :core-protocol:test     # 协议库单元测试（无需真机）
./gradlew :app:assembleDebug      # Debug APK
./gradlew :app:assembleRelease    # Release APK（签名信息经环境变量注入，见下）
```

协议层（`core-protocol`）为纯 Kotlin/JVM 模块，与安卓框架解耦，全部解析逻辑可用模拟卡片数据做单元测试。

## CI/CD

- **CI**（push / PR）：单元测试 → 编译 Debug APK → 上传测试报告与 APK 产物。
- **Release**（推送 `v*` 标签）：单元测试通过 → 签名编译 Release（arm64-v8a / armeabi-v7a / x86_64 拆分包 + 通用包）→ 自动创建 GitHub Release 并附上全部 APK。
  - 本应用为纯 Kotlin 实现、无原生库，**通用包已兼容所有架构**；拆分包用于按架构分发。

### 所需 GitHub Secrets（仅名称，值不入库）

| Secret | 用途 |
| --- | --- |
| `KEYSTORE_BASE64` | 签名密钥库文件的 Base64 |
| `KEYSTORE_PASSWORD` | 密钥库口令 |
| `KEY_ALIAS` | 密钥别名 |
| `KEY_PASSWORD` | 密钥口令 |

工作流中密钥仅经环境变量注入 Gradle，日志自动掩码，构建结束即删除临时密钥库文件。

## 已知边界

- 地铁进出站状态依据卡内进出闸时间推导；站点按编码规则解析为线路号+站点号，个别城市编码规则如有差异会回退显示原始代码。
- 城市代码表收录可核对的银联地区码条目，未收录城市显示原始代码。
- 真实卡片兼容性需实测反馈（云端 CI 仅覆盖协议解析单元测试与构建验证）。
